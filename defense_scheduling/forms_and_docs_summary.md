## To-Do List / Process Flow (rev 1/2026) — the authoritative checklist

Resources: <https://www.rit.edu/computing/phd-computing-and-information-sciences/resources>
(format guidelines, dissertation template, publication requirement policy).

1. **Apply for Graduation** in SIS for the term (spring deadline Apr 1; can file
   "Change to Expected Graduation Term" with Registrar if you slip).
2. **Complete the PhD Degree Certification form**, email to the PhD director assistant **before** your defense.
3. **Submit committee member & defense chair list** as soon as the date is set with committee + chair.
4. **Manuscript** to committee members + GCCIS PhD director **≥ 4 weeks ahead**.
5. **Email Date, Time, Zoom link (if remote) & Abstract** to the PhD director assistant **2–3 weeks prior** (for the announcement).
6. **Revisions:** complete within the committee-agreed window, **up to 3 months** after the defense,
   but **before the RIT term certification date** to graduate that term. *Schedule early enough to allow revision time.*
7. **Publication requirement:** be primary author of ≥1 high-impact (or equivalent) publication.
   Submit your **publication list to Dr. Shi (cc the assistants)**, highlighting the one milestone publication → entered in SIS.
8. **Dissertation submission to RIT Library** (<https://infoguides.rit.edu/thesis-services>):
   - (a) Submit committee/chair/director-**signed Signature Sheet** to Library for RIT archive.
   - (b) Submit an **electronic copy** with an *unsigned* signature sheet page to the Library.
   - (c) **Share proof** of the Library submission email with the PhD office.
   - (d) Order via **ProQuest a hardcover bound copy** (Hardcover, 8.5"×11", double-sided) delivered to the GCCIS PhD office (**student pays**).
9. **SED Survey:** complete the Survey of Earned Doctorates — <https://sed-ncses.org>.

## Applying for Graduation (SIS) — from the PDF

- **Apply:** SIS → Academic Records tile → *Graduation* (left nav) → *Apply for Graduation* →
  select term (read the Anticipated Graduation Date note) → Continue → **Submit Application**.
  (You only see the link if eligible; if already applied you see *View Graduation Status*.)
- **Diploma name** (defaults to legal name): set via Graduation Information → *Enter Diploma Name*,
  or directly any time via Personal Information tile → *Personal Details* → Names. Diacritics allowed; no quotation marks.
- **Diploma address:** Graduation Information → *Enter Diploma Address* → add address (type = Diploma).
- Spring deadline to appear in the commencement book is **April 1** (the PDF is the generic RIT how-to).
